# Capstone — integrated result

**Live URL:** <https://my-username.github.io/my-capstone/>

## What I built

A static "Learning Journal" web app with About, Contact, and Projects sections. It is deployed
for free on **GitHub Pages** via a GitHub Actions workflow, and the repository is configured the
professional way.

## Repository configuration

- **Branch protection** is enabled on `main`: pull requests are required and the CI status check
  must pass before merging.
- CI runs on every push and pull request (`.github/workflows/ci.yml`).
- Deployment to GitHub Pages runs automatically on merge to `main`.

## Built with Kiro

I built and extended this project **with Kiro** — using chat to scaffold and edit code, a
steering file for project conventions, and a spec to add features deliberately.
