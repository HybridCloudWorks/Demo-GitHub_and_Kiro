# My Learning Journal — the course project

This is the real web app you build across the course. It's a **static site** — plain HTML, CSS,
and JavaScript with **no build tools** — so it runs by simply opening `index.html` in a browser.

## Run it locally

You have two easy options:

- **Just open it:** double-click `index.html`, or drag it into a browser.
- **Serve it** (closer to how it runs on the web) with any static server, e.g.:

  ```bash
  # Python (built in on most systems)
  python3 -m http.server 8000
  # then visit http://localhost:8000
  ```

## Files

| File | Purpose |
