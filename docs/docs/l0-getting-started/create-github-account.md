# Create Your GitHub Account

> **Level:** L0 · **Estimated time:** 10 min · **Prerequisites:** an email address

## 🎯 Objectives

By the end of this lesson you will be able to:

- Create a free GitHub account
- Explain what GitHub is used for
- Recognize your **profile** and where your repositories will live

## 📖 Lesson

### What is GitHub?

**GitHub** is a website that stores Git repositories in the cloud. It lets you:

- Keep a backup of your projects online.
- Share your work and collaborate with others.
- Use tools like pull requests and automation (which you'll learn in later levels).

It's free to create an account and free to host public repositories.

### Sign up

1. Go to **[github.com](https://github.com)** and select **Sign up**.
2. Enter your **email address**, a **password**, and a **username**.
   - Your username becomes part of your URLs, e.g. `github.com/your-username`. Pick something
     you're happy to share professionally.
3. Solve the little puzzle to prove you're human, then verify your email address.
4. When asked about a plan, the **Free** plan is all you need for this course.

:::tip Choosing a username
Shorter and simpler is better. You can't easily change it later without breaking links, so
avoid years or trends you might outgrow (e.g. prefer `alexriver` over `alexriver2026xd`).
:::

:::warning Keep your account secure
Use a strong, unique password. Later, consider enabling **two-factor authentication (2FA)** in
your account settings — GitHub increasingly requires it, and it protects your work.
:::

### Look around

Once you're in, visit `https://github.com/<your-username>` — that's your **profile**. Right
now it's empty. Soon it will list your repositories, starting with the one you create in a
couple of lessons.

## ✅ Checkpoint

- [ ] I created a GitHub account and verified my email.
- [ ] I can visit my profile at `github.com/<my-username>`.
- [ ] I understand GitHub hosts my repositories online.

## 🧪 Demo / Try it

Open your profile page and note your username. You'll type it a lot in this course — for
example, your course site will publish to `https://<your-username>.github.io/...`.
