# Create Your GitHub Account

> **Level:** L0 · **Estimated time:** 10 min · **Prerequisites:** an email address

## What you'll get out of this lesson

You'll create a free GitHub account, understand what GitHub is actually for, and know where your
repositories will live once you start creating them.

## What GitHub is, and why you want one

**GitHub** is a website that stores Git repositories in the cloud. On its own that sounds modest,
but it's the difference between a project that only exists on your laptop and one that has a backup,
can be shared with a link, and can be worked on by more than one person.

Concretely, GitHub gives you an off-machine backup of your projects, a way to share your work and
collaborate with others, and access to a whole set of tools built on top of Git: pull requests,
automation, issue tracking, and more. You'll meet those in later levels. For now, the important part
is that creating an account is free, and hosting public repositories is free too.

## Signing up

1. Go to **[github.com](https://github.com)** and choose **Sign up**.
2. Enter an **email address**, a **password**, and a **username**. Take the username seriously for a
   moment: it becomes part of every URL that points to your work, like `github.com/your-username`,
   and it's what collaborators will see. Pick something you'd be comfortable putting on a resume.
3. Solve the little puzzle that proves you're not a bot, then verify your email address from the
   message GitHub sends you.
4. When it asks which plan you want, the **Free** plan is genuinely all you need for this entire
   course. You can always upgrade later if a job or a private project calls for it.

:::tip Choosing a username you'll still like in five years
Shorter and plainer ages better. You can technically change your username later, but doing so
breaks existing links to your work, so it's worth getting close on the first try. Skip the years and
in-jokes: `alexriver` will still look right long after `alexriver2026xd` starts to sting.
:::

:::warning Secure the account now, not later
Use a strong, unique password (a password manager makes this painless). And plan to turn on
**two-factor authentication (2FA)** in your account settings soon. GitHub increasingly requires it
for contributors anyway, and once real work lives in your account, that second factor is what stands
between a leaked password and someone rewriting your projects.
:::

## Have a look around

Once you're in, visit `https://github.com/<your-username>`. That's your **profile**. Right now it's
mostly empty, which is exactly how it should be on day one. In a couple of lessons it'll start
listing the repositories you create, beginning with your first one.

## Quick self-check

- [ ] I created a GitHub account and verified my email.
- [ ] I can open my profile at `github.com/<my-username>`.
- [ ] I understand that GitHub is where my repositories live online.

## Try it

Open your profile page and note your exact username, capitalization and all. You'll type it a lot
from here on. For example, when you publish your course site later in the course, it'll live at
`https://<your-username>.github.io/...`, so it pays to know it cold.
