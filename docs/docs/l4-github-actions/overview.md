# L4 · Automation with GitHub Actions

> **Level:** L4 · **Estimated time:** 10 min · **Prerequisites:** finished Level 3

So far *you* run the checks and *you* publish. Now you'll teach **robots** to do it. GitHub
**Actions** runs automated workflows when things happen in your repo — like running tests on a
pull request or deploying your app when you push to `main`.

## 🎯 What you'll achieve in Level 4

- Understand **CI/CD** and what a workflow is
- Read and write a **GitHub Actions** workflow file
- **Deploy** the project app to GitHub Pages automatically
- Prove it with a graded Actions lab
