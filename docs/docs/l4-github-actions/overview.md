# L4 · Automation with GitHub Actions

> **Level:** L4 · **Estimated time:** 10 min · **Prerequisites:** finished Level 3

Up to now, *you* run the checks and *you* publish the site. It works, but it relies on you
remembering, every time, and being consistent about it. This level hands that repetitive work to
automation. GitHub **Actions** runs workflows when things happen in your repo: run the checks when
someone opens a pull request, deploy the app when a change lands on `main`, and so on. The payoff is
that the tedious, easy-to-forget steps become automatic and reliable.

## What you'll be able to do by the end

- Explain **CI/CD** and what a workflow actually is
- Read and write a **GitHub Actions** workflow file with confidence
- **Deploy** the project app to GitHub Pages automatically
- Prove the skill in a graded Actions lab
