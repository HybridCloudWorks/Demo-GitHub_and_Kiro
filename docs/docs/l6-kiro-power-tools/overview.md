# L6 · Kiro Power Tools

> **Level:** L6 · **Estimated time:** 10 min · **Prerequisites:** finished Level 5

Time to unlock Kiro's most powerful features. You'll connect Kiro to external tools with **MCP
servers**, create your own **custom agents**, and wire Kiro into your **GitHub** workflow so it
helps with issues, branches, and pull requests.

:::note Some parts need accounts/tools
This level is fully hands-on. A few steps require installing a tool (like `uvx`/`npx`) or having
a GitHub account. Each lesson lists its prerequisites, and the account-heavy pieces are marked as
optional **stretch** goals so you can still complete the level.
:::

## 🎯 What you'll achieve in Level 6

- Configure an **MCP server** and call one of its tools
- Define a **custom agent** tailored to a task
- Use Kiro alongside GitHub (issues → branch → PR) on the project
