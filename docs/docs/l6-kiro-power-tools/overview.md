# L6 · Kiro Power Tools

> **Level:** L6 · **Estimated time:** 10 min · **Prerequisites:** finished Level 5

This is where Kiro's most capable features come out. You'll connect Kiro to external tools with
**MCP servers**, so it can do things like fetch web pages or query data. You'll build your own
**custom agents** tuned for specific jobs. And you'll wire Kiro into your **GitHub** workflow so it
helps you move from an issue to a branch to a merged pull request without friction.

:::note Some parts need accounts or extra tools
This level is thoroughly hands-on. A few steps ask you to install a small tool (like `uvx` or
`npx`) or to have a GitHub account. Each lesson lists what it needs up front, and the account-heavy
pieces are marked as optional **stretch** goals, so you can complete the level either way.
:::

## What you'll be able to do by the end

- Configure an **MCP server** and call one of the tools it provides
- Define a **custom agent** tailored to a task you do repeatedly
- Use Kiro alongside GitHub, taking a change from issue to branch to PR on the project
