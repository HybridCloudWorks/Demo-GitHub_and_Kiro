# L1 · Git & GitHub Fundamentals

> **Level:** L1 · **Estimated time:** 10 min · **Prerequisites:** finished Level 0

In Level 0 you made a commit on your own machine. That's the seed. Level 1 grows it into the set of
skills you'll actually use every day: writing commits you can be proud of, working on changes in
parallel without stepping on yourself, and connecting your local repo to GitHub so your work has a
home online.

None of this is advanced. It's the everyday vocabulary of working with code, and once it's second
nature the rest of the course moves a lot faster.

## What you'll be able to do by the end

- Understand what a commit really captures, and write messages your future self will thank you for
- Create and switch between **branches** to keep work-in-progress separate from your stable code
- Connect a local repo to a **remote** on GitHub, then **push** and **pull** to stay in sync
- Use a `.gitignore` file to keep generated junk and secrets out of your history
- Prove you can put it all together in a **graded lab**
