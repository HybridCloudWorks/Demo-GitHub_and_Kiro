# L1 · Git & GitHub Fundamentals

> **Level:** L1 · **Estimated time:** 10 min · **Prerequisites:** finished Level 0

In Level 0 you made your first commit locally. Now you'll learn the everyday Git skills that
carry you through the rest of the course — and you'll connect your local repo to GitHub.

## 🎯 What you'll achieve in Level 1

- Understand commits more deeply and write good commit messages
- Create and switch **branches**
- Connect a local repo to a **remote** on GitHub and **push**/**pull**
- Use a `.gitignore` to keep junk out of your history
- Prove it all with a **graded lab**

## 🧭 The lessons in this level

1. [Commits & good messages](./commits-and-messages.md)
2. [Branches](./branches.md)
3. [Remotes: push & pull](./remotes-push-pull.md)
4. [Ignoring files with .gitignore](./gitignore.md)
5. [🧪 Lab: your first graded exercise](./lab.md)
