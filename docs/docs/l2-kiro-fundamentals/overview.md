# L2 · Kiro Fundamentals

> **Level:** L2 · **Estimated time:** 10 min · **Prerequisites:** finished Level 1

This is where Kiro enters the picture in earnest. **Kiro** is an AI-powered development
environment: you describe what you want in plain language, and Kiro helps you read, write, and
change code. If you've used a code editor before, think of Kiro as one that can also hold a
conversation about your project and act on it.

The goal of this level is twofold. You'll get comfortable moving around Kiro, and you'll use it to
scaffold the **real project** that you'll extend for the rest of the course. From here on, the work
gets tangible.

## What you'll be able to do by the end

- Open a project as a Kiro **workspace** and know what Kiro can see and touch
- Use Kiro **chat** to ask questions and request changes, and get better results by asking better
- Read and edit code with Kiro's help, then commit it with the Git skills from Level 1
- Scaffold the project app and tag your first real milestone, `milestone-l2`
