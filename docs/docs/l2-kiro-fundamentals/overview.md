# L2 · Kiro Fundamentals

> **Level:** L2 · **Estimated time:** 10 min · **Prerequisites:** finished Level 1

Now you meet **Kiro** properly. Kiro is an AI-powered development environment: you describe what
you want in plain language, and Kiro helps you write and change code. In this level you'll learn
your way around and use Kiro to scaffold the **real project** you'll grow for the rest of the
course.

## 🎯 What you'll achieve in Level 2

- Understand the Kiro **workspace** and how to open a project
- Use Kiro **chat** to ask questions and request changes
- Read and edit code with Kiro's help
- **Scaffold the project app** — your first real milestone (`milestone-l2`)
